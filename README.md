# 御AI天牢锁（YUAI Tianlao Lock）

**把文件夹锁成加密保险柜。防木马、防黑客、防 AI 直访文件。**

任何访问都必须经过本机 Windows Hello 生物验证（刷脸 / PIN / 指纹）或主卡 12 词，否则文件打不开。没有"找管理员远程解锁"这条路——加密密钥是本机 Hello 签名与主卡口令共同派生，服务端也解不开。

> 当前状态：公开测试版。桌面应用安装包见本仓库 [Releases](../../releases)。

## 它解决什么

- **木马 / 黑客**：文件在磁盘上是 AES-GCM 密文，偷走 `.vault` 文件也读不出内容
- **AI 直访文件**：AI 就算能操作这台电脑，没有你的 Hello 生物验证也打不开柜子
- **换机 / 重装 / Hello 丢失**：主卡或单柜副卡的 12 个词可以直接解出密钥，不依赖 Windows 账户

## 下载与安装

1. 打开本仓库 [Releases](../../releases)，下载最新的 `御AI天牢锁-安装程序.exe`
2. 双击安装（Windows 10/11，需管理员权限写入文件关联）
3. 首次加密前请先生成**主恢复卡**：面板 → 更多功能 → 主卡 → 生成/绑定。主卡是换机、重装、Hello 丢失时唯一的救命凭证，请**打印或抄写**，不要只留电子版

## 快速上手

- **加密**：右键任意文件夹 →「用御AI天牢锁加密」→ 确认框 + Windows Hello → 生成同目录的 `.vault`；原文件夹移入过渡备份（验收后自行删除）
- **解锁**：双击 `.vault` → Windows Hello → 解密回原位置
- **灾备**：Hello 不可用时，右键 `.vault` →「恢复卡解锁」→ 输入主卡 12 词（新机器只有单柜副卡时，需同时指定该副卡对应的柜子）

## WorkBuddy 连接器

在 WorkBuddy 连接器市场搜索「**御AI天牢锁**」即可启用。连接器是**AI 入口**，不是工具本体：

- 可让 AI 查看本机保险柜清单、查工具状态、发起文件夹加密
- **加密仍会在你本机弹确认框 + Hello，AI 无法绕过**；AI 看不到文件原文
- 由 AI 发起的操作会在工具的操作日志中留痕（标记来源）
- 解锁、删卡、换卡仍需在桌面应用内操作

> 连接器是本地 stdio 进程，需要桌面应用已安装才能发起加密；只读查询不需要。

## 安全模型（简述）

```
柜子里的 A = DK XOR h
h = Windows Hello 对固定消息的 RSA 签名（本机 TPM 保管）
DK = AES 密钥，由主卡/副卡 12 词经 scrypt 解封
```

- 主卡 12 词可开所有绑定柜；单柜副卡只开一个柜，可在原机作废
- 副卡支持可选有效期（时间戳绑进 AES-GCM 的 AAD，改时间戳即作废）
- 全部密钥材料只在本机，官网不持有明文，也解不开任何柜子
